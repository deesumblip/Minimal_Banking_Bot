What you covered:

- A flow can collect multiple slots in sequence, each with its own `collect:` step, description, and rejection rules
- Slots collected earlier in a flow are available to later steps in the same flow
- `persisted_slots` at the flow level carries any listed values into the next session
- Branching with `if:` / `else:` lets a flow take different paths based on collected values
- The same slot can be reused across flows without re-asking the user if the value is already set
