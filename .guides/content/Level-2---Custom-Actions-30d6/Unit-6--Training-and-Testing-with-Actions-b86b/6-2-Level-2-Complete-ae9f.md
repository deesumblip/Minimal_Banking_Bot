**What you covered:**
 
- Custom actions run in a separate action server process and do not require retraining when you edit the Python code
- Every action is a class with `name()` (the lookup key) and `run()` (your logic)
- Actions must be listed in the domain under `actions:`, the Python file alone is not enough
- Response steps and action steps use identical syntax in a flow and can be chained in any order
